# eNet AI · первая версия дизайна

Первый прототип интерфейса из архива `chatly.zip`. Визуальное оформление сохранено без изменений. Desktop-оболочка на Tauri 2. Реальная AI-модель и API не подключены: текущие ответы формирует демонстрационная заглушка.

Сборки Windows `.exe` и Ubuntu `.deb` выполняются в GitHub Actions.
